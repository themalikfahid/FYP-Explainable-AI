# Z-Alizadeh Sani coronary artery disease dataset

Source: UCI Machine Learning Repository, dataset 412 (donated 2017), https://archive.ics.uci.edu/dataset/412/z+alizadeh+sani
303 patients (216 CAD, 87 normal), 54 features + target `Cath` (CAD = >= 50% diameter narrowing at angiography).
File: z_alizadeh_sani.xlsx (unchanged copy of "Z-Alizadeh sani dataset.xlsx").
Used by the `cad` task (27 screening features, see ml/data.py). No duplicates, no missing values.
