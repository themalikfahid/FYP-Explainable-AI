# Model evaluation

This file is generated by `python scripts/make_eval_report.py` from `artifacts/models/*/metadata.json`,
`global_shap.json` and `artifacts/eval/t1d_external_check.json`. Do not edit the numbers by hand; retrain
(`python -m ml.train`) and regenerate instead. Interpretation is in docs/MODEL_METHODOLOGY.md.

All numbers are retrospective results on public datasets. They describe software and model behaviour on
those datasets, not clinical accuracy.

**Metric notes.** Macro scores weight every class equally (important for the rare heart grades); weighted
scores weight by class frequency. Brier score is the mean squared error of the probability vector (lower is
better; for 5 classes it ranges 0 to 2). ECE is the top-label expected calibration error over 10 equal-width
bins (lower is better). Confidence intervals come from 1000 bootstrap resamples of the small test sets and
are wide; differences between models that fall inside each other's intervals are not evidence that one model
is better.

## Exploratory check of the diabetes screen on the local type 1 cohort

Run with `python -m ml.external_t1d_check` on 85 de-identified, diagnosed T1D children and adolescents. Because every person in this cohort has T1D, the only quantity that can be estimated is the share the screen flags as positive (a rough sensitivity). It is **not** a validation.

27.1% of the cohort had none of the five symptoms that exist in both datasets.

| Scenario | Hybrid: share positive | RF: share positive | ANN: share positive | Hybrid: share high risk |
|---|---|---|---|---|
| sex=female, age=as_recorded | 58.8% | 69.4% | 54.1% | 44.7% |
| sex=male, age=as_recorded | 41.2% | 62.4% | 40.0% | 31.8% |
| sex=female, age=clipped_to_16 | 60.0% | 69.4% | 60.0% | 45.9% |
| sex=male, age=clipped_to_16 | 42.4% | 62.4% | 42.4% | 32.9% |

Caveats (from the script):

```
* every cohort member has T1D, so only sensitivity (share flagged positive) can be
    estimated; specificity cannot;
  * symptoms were recorded around/after diagnosis (retrospective), not before it;
  * only 5 of the 14 symptom questions exist in the cohort; the other 9 are set to
    "No" (a conservative assumption that can only lower the score);
  * sex is not recorded, so results are reported for both values;
  * cohort ages (4-18) are mostly below the training range (16-90), so the
    model is extrapolating; a sensitivity analysis clips age to 16.
```
